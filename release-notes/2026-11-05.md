# OpenClaw v2026.11.5 版本發佈說明

> AI 草稿，待人工審閱。內容依官方 release 翻譯整理，未驗證上游原始碼；三星項目的實作流程圖、Breaking Changes 與升級步驟須於合併前人工確認。

## ⚠️ 升級前必讀

### Breaking Changes 摘要

| 項目 | 影響 | 行動 |
|------|------|------|
| **Breaking: harness and plugin session control** (#175837) | Third‑party harnesses must register session‑keyed active runs inside the host `runAttempt` callback and retain the returned cleanup function. Plugin RPC handlers must replace `chatAbortControllers`/`chatQueuedTurns` with authorized Gateway method dispatch. Start‑owner observations use `startDeadlineAtMs` instead of `expiresAtMs`; bundled consumers are migrated. | Review and update all custom harnesses and plugins to use the new session‑keyed API. |

### 新功能亮點

- **Restart‑safe conversations** – Queued messages, send permissions, and final chat writes are retained across Gateway restarts. (#196923, #196540, #196493)
- **Safer updates** – Failed Doctor or Gateway startup rolls back an activated update; restored npm packages remain readable by non‑root services. (#197851, #193272)
- **Telegram widgets** – Interactive widgets now render in Telegram messages, including private‑chat topics. (#196991, #198022)
- **Faster memory recovery** – Large memory‑index rebuilds finish reliably, and embedding indexing recovers when a gateway truncates a batch‑limit error. (#196378, #187797)
- **More reliable model fallback** – A configured primary account no longer blocks Claude CLI fallback, and OpenAI sessions recover from compaction item conflicts. (#198427, #198357)

## 概述

- ⭐⭐⭐ Restart‑safe conversations: Queued messages retained across Gateway restarts. (#196923, #196540, #196493)  
- ⭐⭐⭐ Safer updates: Failed Doctor/Gateway startup rolls back activated update; npm packages readable by non‑root. (#197851, #193272)  
- ⭐⭐ Telegram widgets: Interactive widgets render in Telegram messages, including private‑chat topics. (#196991, #198022)  
- ⭐⭐ Faster memory recovery: Memory‑index rebuilds finish reliably; embedding indexing recovers from batch‑limit errors. (#196378, #187797)  
- ⭐⭐ More reliable model fallback: Primary account no longer blocks Claude CLI fallback; OpenAI sessions recover from compaction conflicts. (#198427, #198357)  
- ⭐⭐ Usable device folders: Device folders remain selectable with default runtime; compact menu row. (#190065, #190088)  
- ⭐⭐ Content boundaries: Binary attachments no longer become garbled prompt text; authenticated browser CDP URLs stay out of tool results. (#198309, #196262)  
- ⭐⭐ Compaction: `maxSummaryChars` controls summary character cap. (#196207)  
- ⭐⭐ Knowledge: Keep pages within read‑sized budget; extract sections without loading oversized page. (#186270)  
- ⭐⭐ Breaking: harness and plugin session control: Third‑party harnesses must register session‑keyed active runs; plugin RPC handlers must replace `chatAbortControllers`/`chatQueuedTurns`; start‑owner observations use `startDeadlineAtMs`. (#175837)  
- ⭐⭐ Authorization: Queued automation runs recheck access to owner‑private memory before starting; failed child results remain deliverable after parent turn ends. (#198697, #197658)  
- ⭐⭐ Conversation history: Refreshes retain keyed commentary; transcript reads survive concurrent database preparation; completed empty attempts no longer clutter history. (#188180, #188055, #188111)  
- ⭐⭐ Gateway recovery: Resume interrupted turns after workspace preparation; preserve graceful shutdown when restart stalls; acknowledge uploads before workspace preparation. (#196423, #188047, #188728)  
- ⭐⭐ Gateway reload: Configuration updates no longer hang when file watcher wins reload race; MCP listener work cancelled on shutdown. (#192701, #197119)  
- ⭐⭐ Cron scheduling: Preserve scheduled account selection, restart retry deadlines, completion‑run identity; handle late wakeups without dropping jobs. (#180677, #197449, #197484)  
- ⭐⭐ Cron lifecycle: Config hot reload no longer aborts in‑flight jobs; startup deadlines and cancellation remain effective; disabled automatic scheduling releases idle workers. (#197606, #188982, #196387)  
- ⭐⭐ Quiet automations: False trigger checks stay out of chat; main‑session automations can run from a DM without failing before the model call. (#188594, #188700, #180603)  
- ⭐⭐ Telegram replies and approvals: Restore ACP replies in progress‑stream mode; keep approvals inside their private or forum topic. (#197191, #198038, #192162)  
- ⭐⭐ Telegram hooks and controls: Supply the runtime session key to delivery hooks; render disabled buttons as non‑interactive. (#197519, #191647)  
- ⭐⭐ Channels: Deliver captioned Feishu media with block streaming disabled; normalize Unicode directory matches in Matrix and Mattermost; prevent crafted Matrix formatting from stalling mention checks. (#191585, #187881, #187199, #184432)  
- ⭐ iOS voice: Keep Talk working while the phone is locked; prevent the speech‑permission Allow action from crashing the app. (#187864, #196822)  
- ⭐ Talk startup: Voice requests no longer stall before the backing agent starts; failed startup registrations are released. (#183586, #187840)  
- ⭐ Control UI: Prevent WebKit freezes while replacing an opening menu; avoid event‑listener failures while chat details update. (#198658, #198380)  
- ⭐ Host desktop: Finish VNC authentication during readiness probes so repeated checks do not trigger server lockouts. (#193487)  
- ⭐ Keyboard and search: Preserve IME navigation in the worktree picker; provide a keyboard skip to the composer; match canonically equivalent Unicode attachment names. (#187732, #180896, #187674)  
- ⭐ UI responsiveness: Avoid accumulated WebKit slowdown after repeated session switches; release static loading animations; settle aborted data‑URL previews. (#194027, #194146, #191451)  
- ⭐ Provider continuity: Keep provider checkpoints available across credential‑source and model switches. (#200063, #200208)  
- ⭐ OpenAI and Anthropic: Preserve saved‑context replay when hooks override requests; keep Anthropic session prompts stable across completion wakes and message routes. (#199451, #197835, #197925)  
- ⭐ Claude CLI and providers: Recover after a failed live‑session cleanup; reconnect after settled local transport failures; include Claude CLI models without requiring an Anthropic model pin. (#198224, #187375, #191148)  
- ⭐ Model discovery: Avoid slow reads with large model configurations; recover provider discovery during concurrent SDK imports. (#198837, #196448)  
- ⭐ Provider routing: Keep OpenRouter requests on their own endpoint; config writes no longer silently switch models to API‑key billing. (#185294, #191326)  
- ⭐ Rate limits: Respect the configured maximum retry delay after tool execution instead of holding a session lane for an oversized wait. (#197611)  
- ⭐ Doctor and upgrades: Bound Doctor startup waits, honor SIGTERM, avoid stalling live sessions during hosted checks. (#187936, #191125)  
- ⭐ Update reliability: Keep database restoration available while progress polls during Doctor; tolerate harmless empty‑WAL transitions; preserve failed post‑plugin Doctor warnings; recognize successful Gateway startup before post‑update checks. (#192083, #193134, #192942)  
- ⭐ macOS onboarding: Preserve the installer terminal handoff so onboarding can install plugins without detached npm terminal failures. (#200247)  
- ⭐ Stored state: Restore cold transcripts for renamed agents before repair; tolerate retained deleted‑agent databases; isolate held databases until explicit restoration. (#196079, #198145, #198180)  
- ⭐ Backups: Compact snapshots inside the staging directory; inspect the backup engine without copying the live database; preserve SQLite corruption diagnostics. (#194230, #194234, #194497)  
- ⭐ Backup diagnostics: Identify busy files during backup capture; retry transient Windows access failures without weakening integrity checks. (#193685)  
- ⭐ Update recovery: Handle state‑path aliases, live cleanup writes and environment‑only service overrides without losing restoration progress. (#189004, #189628, #196371)  
- ⭐ Update cleanup: Avoid false failures from leftover snapshot copies or NFS snapshot‑directory cleanup; preserve external plugin data during rehearsal. (#193702, #195409, #196301)  
- ⭐ Cold storage and startup: Avoid worker out‑of‑memory failures during large transcript‑index repair; restore cold PostgreSQL conversations after idle readers close; avoid database‑clone stalls during Gateway startup. (#194099, #189991, #190918)  
- ⭐ Memory and SQLite: Avoid redundant Dreaming inventory reads; release completed SQLite readers; prevent cursor restarts. (#180692, #190242)  
- ⭐ Plugin rebuilds: Release obsolete plugin‑generation state instead of growing Gateway memory after every rebuild. (#199042)  
- ⭐ Packages and discovery: Ship PostgreSQL declarations; point packaged plugin exports at compiled runtime files; restore Bonjour discovery in npm installs. (#188091, #188639, #199156)  
- ⭐ Browser and workflow paths: Preserve native CORS preflights; avoid Lightpanda navigation timeouts; keep literal workflow paths intact instead of trimming whitespace. (#185028, #196400, #187785)  
- ⭐ CLI and configuration: Offer help flags in shell completion; allow dotted‑path insertions in JSON and YAML; stop pending cron inventory reads on interrupt. (#187799, #187828, #187726)
