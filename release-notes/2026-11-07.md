### Breaking Changes 摘要

| 項目 | 影響 | 行動 |
|------|------|------|
| Session control — 破壞性 SDK 變更 ([#175837](https://github.com/openclaw/openclaw/pull/175837)) | 將 session-keyed `setActiveEmbeddedRun(...)` 註冊移至主機提供的 `runAttempt` 回調；未獲准許的註冊現在會回報 `SESSION_CONTROLLER_ADMISSION_REQUIRED`。 | 將相關外掛遷移至新的 `runAttempt` 回調模型，並保留原有清理函式。 |
| Gateway methods — 破壞性 SDK 變更 ([#175837](https://github.com/openclaw/openclaw/pull/175837)) | 以 `dispatchGatewayMethod` 取代可變的 `chatAbortControllers` 與 `chatQueuedTurns` 存取；外掛資訊清單需宣告 `contracts.gatewayMethodDispatch: ["authenticated-request"]`。 | 更新外掛資訊清單並改用 `openclaw/plugin-sdk/gateway-method-runtime`。 |
| Start observation — 破壞性 SDK 變更 ([#175837](https://github.com/openclaw/openclaw/pull/175837)) | `AgentTurnStartOwner.observe()` 使用者需從 `expiresAtMs` 改用 `startDeadlineAtMs`；此為執行開始期限，非執行逾時，且無相容別名。 | 參閱 `docs/plugins/sdk-migration.md` 進行遷移，並更新所有消費者程式碼。 |

### 新功能亮點

- **Conversation recovery** — 跨 Gateway 重新啟動恢復中斷的回覆與子結果，不遺失待處理工作。
- **Reliable automations** — 讓自動化的擁有者對話修復失敗，並區分已恢復或有意跳過的執行與真正失敗。
- **Smoother updates** — 在結構變更、忙碌資料庫與保留的恢復狀態下完成 Git 與套件更新。
- **Responsive Gateway** — 在緩慢檔案系統作業、大型恢復套件與頁面提取期間，保持聊天、就緒檢查與無關工作階段回應。
- **Browser pairing** — 以 Gateway 主機核准的短代碼配對另一個瀏覽器，並在等待核准時提供更明確說明。
- **Current ChatGPT catalogs** — 無需等待下一次 OpenClaw 版本即可發現新訂閱模型，並讓登入探索與 npm 獨立。
