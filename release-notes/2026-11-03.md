## 功能更新

### ⭐⭐⭐ Private task results ([#188490](https://github.com/openclaw/openclaw/pull/188490))
- **用途**: 保留私密 subagent 完成不會進入 streamed chat replies。
- **解決問題**: 私密子代理完成可能被流式聊天回覆意外顯示。
- **影響**: 提升私密 task results 的保密性。

### ⭐⭐ Reliable child-task handoffs ([#178893](https://github.com/openclaw/openclaw/pull/178893); related [#178565](https://github.com/openclaw/openclaw/pull/178565))
- **用途**: 允許父層在取消子任務後交接到替補工作，避免已取消子任務的 completion receipt 阻擋交接。
- **解決問題**: 取消子任務後無法交接。
- **影響**: 改善 child-task handoff 可靠性。

### ⭐⭐ Faster, responsive Gateway ([#192217](https://github.com/openclaw/openclaw/pull/192217), [#184433](https://github.com/openclaw/openclaw/pull/184433))
- **用途**: 減少 startup module-file loading overhead，並避免 abort-command detection 遇到長 punctuation runs 時停滯。
- **解決問題**: Gateway 啟動慢、abort 偵測停滯。
- **影響**: Gateway 啟動更快、回應更即時。

## 安全性提升

### ⭐⭐⭐ Credential isolation ([#178444](https://github.com/openclaw/openclaw/pull/178444), [#177974](https://github.com/openclaw/openclaw/pull/177974), [#189423](https://github.com/openclaw/openclaw/pull/189423))
- **用途**: 讓 reused 和 cached plugin results 限定在 connection credentials scope，並讓其他 plugins 的 transport hooks 使用 provider origin。
- **解決問題**: Plugin 結果與憑證隔離不足。
- **影響**: 降低 plugin 結果外洩風險。

### ⭐⭐⭐ Credential redaction ([#190618](https://github.com/openclaw/openclaw/pull/190618), [#178745](https://github.com/openclaw/openclaw/pull/178745))
- **用途**: 從 configuration reads 遮蔽 inline environment credentials，並從 Exa errors 遮蔽 reflected search credentials。
- **解決問題**: 憑證可能出現在設定讀取或錯誤中。
- **影響**: 降低 credential exposure。

### ⭐⭐⭐ Child-process environments ([#179198](https://github.com/openclaw/openclaw/pull/179198), [#179415](https://github.com/openclaw/openclaw/pull/179415))
- **用途**: 防止 managed Signal daemons 和 bundled language servers 繼承 unrelated Gateway secrets。
- **解決問題**: 子進程環境可能繼承不相關 Gateway secrets。
- **影響**: 降低 Gateway secret 外洩。

### ⭐⭐⭐ Verified workspace connections ([#125646](https://github.com/openclaw/openclaw/pull/125646), [#190002](https://github.com/openclaw/openclaw/pull/190002))
- **用途**: 在空 fingerprint 時保留 saved node certificate pins，並在傳送 credentials/data 前驗證 workspace-transfer certificates。
- **解決問題**: 工作區連線憑證驗證不足。
- **影響**: 提升工作區連線安全性。

### ⭐⭐⭐ Bounded authentication ([#189144](https://github.com/openclaw/openclaw/pull/189144))
- **用途**: 停止 stalled provider authentication at the run deadline，並在 authentication work 傳播取消。
- **解決問題**: Provider 驗證可能 stalled。
- **影響**: 提升驗證 deadline 與取消行為。

### ⭐⭐⭐ Search and memory credentials ([#190706](https://github.com/openclaw/openclaw/pull/190706), [#184966](https://github.com/openclaw/openclaw/pull/184966))
- **用途**: 讓 Firecrawl search/scrape keys 與 scoped endpoints、embedding credentials 與 destination 關聯。
- **解決問題**: 憑證範圍不足。
- **影響**: 降低憑證外洩。

### ⭐⭐ Sandboxed image access ([#176203](https://github.com/openclaw/openclaw/pull/176203))
- **用途**: 在 Full Access mode 下，將 required-sandbox image previews 限制在 allowed folders，同時保留 explicit administrator image allowances。
- **解決問題**: 圖片預覽可能超出 allowed folders。
- **影響**: 限制圖片存取並保留管理者允許。

### ⭐⭐ Authentication errors ([#173970](https://github.com/openclaw/openclaw/pull/173970), [#181597](https://github.com/openclaw/openclaw/pull/181597))
- **用途**: 讓 credential-read failures 不會被視為 missing credentials，並拒絕明確選取屬於不相容 providers 的 auth profiles。
- **解決問題**: 驗證錯誤處理不足。
- **影響**: 改善憑證與 provider 驗證錯誤處理。

## 錯誤修復

### ⭐⭐ Visible tool failures ([#182458](https://github.com/openclaw/openclaw/pull/182458); related [#99645](https://github.com/openclaw/openclaw/issues/99645))
- **用途**: 回報未回答的工具失敗，而不是將未完成的 user-addressed turn 視為成功。
- **解決問題**: 工具失敗未被回報，可能讓 turn 被誤判成功。
- **影響**: 提升可見性與錯誤處理。

### ⭐⭐ Channel safety ([#174552](https://github.com/openclaw/openclaw/pull/174552), [#186243](https://github.com/openclaw/openclaw/pull/186243))
- **用途**: 讓 incoming Twitch IRC content 不進入 parser error logs，並在多個 Tlon approvals pending 時要求 explicit request IDs。
- **解決問題**: Channel parser error logs / approval 需求不足。
- **影響**: 提升 channel safety。

### ⭐⭐ Update recovery ([#181906](https://github.com/openclaw/openclaw/pull/181906))
- **用途**: 在 initial package-presence check timeout 時安全 recover，要求 fresh valid directory identity before replacement，並保留 rollback。
- **解決問題**: Update recovery 風險。
- **影響**: 提升更新恢復可靠性。

### ⭐ Scheduled jobs ([#175678](https://github.com/openclaw/openclaw/pull/175678), [#168985](https://github.com/openclaw/openclaw/pull/168985))
- **用途**: 處理 queued cron storage failures without exiting Gateway，並清除 one-shot cleanup when job becomes recurring。
- **解決問題**: Scheduled jobs 可能 exit Gateway。
- **影響**: 穩定 scheduled jobs。

### ⭐ Updates ([#177792](https://github.com/openclaw/openclaw/pull/177792), [#187998](https://github.com/openclaw/openclaw/pull/187998))
- **用途**: 讓 profile-backed updates 辨識自己的 maintenance lock，並在 ledger writes deferred 時保留 cancellation。
- **解決問題**: Profile-backed updates 狀態不足。
- **影響**: 改善 updates。

### ⭐ Anthropic usage caps ([#176186](https://github.com/openclaw/openclaw/pull/176186); related [#176179](https://github.com/openclaw/openclaw/issues/176179))
- **用途**: 辨認 exhausted plural usage-limit errors without spending transient rate-limit retry budget。
- **解決問題**: Usage cap 錯誤未被正確辨識。
- **影響**: 避免不必要 rate-limit retry。

### ⭐ Terminal sessions ([#172431](https://github.com/openclaw/openclaw/pull/172431))
- **用途**: 將 /reset soft 轉發給 Gateway instead of hard-resetting session。
- **解決問題**: Terminal session reset 過於 aggressive。
- **影響**: 改善 session 控制。

### ⭐ Git recovery ([#176006](https://github.com/openclaw/openclaw/pull/176006))
- **用途**: 在 Git repair 時保留 uncertain command failures rather than treating unconfirmed operation as successful。
- **解決問題**: Git recovery 可能誤判成功。
- **影響**: 提升 Git recovery 可靠性。

### ⭐ Memory provider selection ([#186310](https://github.com/openclaw/openclaw/pull/186310))
- **用途**: 接受 mixed-case none and auto provider values。
- **解決問題**: Provider selection 大小寫不足。
- **影響**: 改善記憶體 provider 設定。
